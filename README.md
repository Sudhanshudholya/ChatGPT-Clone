# ChatGPT Clone 🤖

This is a **ChatGPT Clone** built using React.js.
It provides a simple and responsive chat interface inspired by ChatGPT.

## 🚀 Features

* Chat with AI
* Chat history
* New chat
* Responsive design
* Simple and clean UI
* Mobile, Tablet and Desktop support

## 🛠️ Tech Stack

* React.js
* Vite
* JavaScript
* CSS
* AI API

## ⚙️ Installation

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd chatgpt-clone
npm install
npm run dev
```
